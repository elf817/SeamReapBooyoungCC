# Handoff: Siem Reap Booyoung Country Club — 공식 홈페이지

## Overview
캄보디아 시엠립 소재 18홀 골프장 "Booyoung Country Club"의 신규 홈페이지 디자인입니다.
목적은 **온라인 예약이 아니라 정보 제공과 전화·카톡 문의 유도**입니다. (예약/결제 기능은 범위 밖 — 절대 추가하지 마세요.)
주요 고객은 한국인 골프 관광객과 시엠립 현지 거주 골퍼입니다. 카피는 전부 한국어, 라벨/키커만 영문.

## About the Design Files
이 폴더의 HTML 파일은 **디자인 레퍼런스(프로토타입)** 입니다. 그대로 배포할 프로덕션 코드가 아닙니다.
개발 시에는 대상 코드베이스의 환경(Next.js / React / Vue 등)과 기존 패턴·컴포넌트·라우팅 규약에 맞춰 **이 디자인을 재구현**하세요.
아직 코드베이스가 없다면 Next.js(App Router) + TypeScript + CSS Modules 또는 Tailwind 조합을 권장합니다 — 정적 콘텐츠 위주이므로 SSG로 충분합니다.

원본 `Siem Reap Booyoung CC.dc.html` 은 스트리밍 프리뷰용 런타임(`support.js`) 위에서 동작하는 파일이라, 브라우저에서 단독 실행하면 `{{ }}` 홀이 채워지지 않습니다. **마크업/스타일/카피의 출처로만 읽으세요.** 실제 값은 파일 하단 `<script data-dc-script>` 안의 `Component` 클래스 `renderVals()` 에 전부 들어 있습니다 (홀 18개 데이터, FAQ, 공지 목록 등 그대로 복사해 쓰면 됩니다).

## Fidelity
**High-fidelity.** 색·타이포·여백·문구 모두 최종안 기준입니다. 픽셀 단위로 재현하되, 사진은 전부 자리표시자이므로 실제 이미지로 교체해야 합니다.

## Interactions & Behavior
- 탭(코스 OUT/IN, 시설 3종, 게시판 3종): 선택 시 배경 `#1e3a2b`+크림 글자, 비선택은 투명+`#3d4438`. 보더는 항상 `1px solid rgba(30,58,43,0.2)`.
- FAQ 아코디언: 한 번에 하나만 열림(단일 인덱스 state). 같은 항목 재클릭 시 전체 닫힘.
- 링크 hover: 텍스트 색 `#1e3a2b` → `#a8823f`. (전역 `a` / `a:hover` 규칙)
- 애니메이션·트랜지션 없음. 필요하다면 150ms `ease` 색상 전환 정도만.
- 반응형: 현재 디자인은 데스크톱(1440px 기준) 전용. 모바일 대응은 미설계 — 구현 시 3열 그리드 → 1열, 헤더 → 햄버거 메뉴, Hero H1 → 40px 수준으로 축소 제안. **별도 확인 필요.**
